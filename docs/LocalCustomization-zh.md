# 方志项目本地改动与交付说明

更新日期：2026年11月25日。

## 本次交付的改动

1. **中文方志抽取提示词**：修改 `lightrag/prompt.py`，涵盖原生JSON、文本格式、补抽、实体描述合并及检索回答等提示。原生抽取规范已更换为用户提供的v1.1版本：15类实体、45种关系，要求使用固定英文类型与关系标识，实体名称和描述使用中文。
2. **保留可选研究适配代码**：`lightrag/extraction/`、`prompts/fangzhi/` 和 `operate.py` 内的接入代码支持另一套研究JSON的校验、存档和图谱转换，并包含对应测试与示例。用户当前选择原生提示词模式，研究模式保持关闭；历史方案详见 [FangzhiSchemaIntegration-zh.md](FangzhiSchemaIntegration-zh.md)。
3. **补齐网页操作界面**：原先本目录没有 `lightrag/api/webui/` 网页产物，服务会跳转到接口文档。本次提交同时包含已重新构建的管理界面、工作区界面及其静态资源，下载仓库后无需先构建网页即可使用 `/webui/`。后续修改网页源码仍需重新构建。
4. **关系中文显示**：45种领域关系英文标识到中文名称的显示映射与v1.1逐项核对一致，应用于图上标签、右侧详情、节点展开和关系编辑后的显示。多个关系分别显示；未知关键词保留原文。存储和编辑使用原始标识。图例补齐15类实体的中文名称；该显示层不会校验或修复历史关系。
5. **图谱文字可读性**：关系文字设为16像素、字重600；实体文字设为20像素。图谱缩放主要改变节点位置和间距，不能代替固定屏幕字号设置。
6. **固定项目启动目录**：新增根目录 `启动方志LightRAG.cmd`，先进入脚本所在目录，再通过当前虚拟环境或Python模块方式启动服务，避免全局 `lightrag-server` 命令关联到另一份本地项目。
7. **忽略本地运行资料**：补充本地备份、书目元数据、接入报告、上传文件及图谱工作目录的忽略规则。个人 `.env`、模型密钥、真实文献与图谱数据不在本次提交中。

## 使用方式

先按项目 `env.example` 创建个人 `.env`，配置自己的大模型与向量模型连接。当前原生模式使用以下设置：

```dotenv
FANGZHI_SCHEMA_ENABLED=false
ENTITY_EXTRACTION_USE_JSON=true
SUMMARY_LANGUAGE=Chinese
WORKING_DIR=./rag_storage_fangzhi
INPUT_DIR=./inputs_fangzhi
WORKSPACE=fangzhi
```

在本项目根目录双击 `启动方志LightRAG.cmd`，或执行：

```powershell
python -m lightrag.api.lightrag_server
```

启动后打开终端显示地址下的 `/webui/`，而不是 `/docs` 接口文档。Python及项目依赖须先按README安装。

修改网页源码后，在 `lightrag_webui/` 内运行：

```powershell
bun install --frozen-lockfile
bun run build
```

生成结果写入 `lightrag/api/webui/`。本分支已取消对该目录的忽略，网页文件及重新构建后产生的新文件名都可以正常提交。更新后在浏览器按Ctrl+F5加载新版文件。
